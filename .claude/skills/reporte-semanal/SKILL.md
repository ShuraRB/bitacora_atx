# Reporte semanal

1. Agrupa las tareas por proyecto.
2. Suma las horas de cada proyecto y el total general.
3. Escríbelo con el formato de `formato.md`.
4. Si falta un dato (por ejemplo, las horas), pregúntalo: no lo inventes.

Al terminar, indica cuántas tareas incluiste.
